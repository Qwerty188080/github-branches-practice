# Учебный веб-проект — Git branches

Проект используется для практической работы 3.1.30 «Создавать и использовать ветки в GitHub».

## Файлы
- `index.html` — главная страница
- `style.css` — стили сайта
- `portfolio.html` — учебная страница портфолио (добавляется в ветке `feature/portfolio`)

## Практическая задача
Создать отдельную ветку `feature/portfolio`, добавить страницу портфолио, выполнить коммит, опубликовать ветку на GitHub и создать Pull Request.
# Сервис бронирования

## Описание
Учебный веб-проект создан в рамках практических занятий по веб-разработке.

## Основные возможности
- Просмотр страниц сайта
- Навигация между разделами
- Удобный интерфейс

## Используемые технологии
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Структура проекта
- `index.php` — главная страница
- `css/` — файлы стилей
- `js/` — JavaScript-функции
- `images/` — изображения сайта

## Запуск проекта
1. Скачать или клонировать репозиторий.
2. Открыть папку проекта.
3. Запустить сайт.
